# django/weblate

The tables Django creates from the models of [apps/djangoer/examples/weblate](../../../apps/djangoer/examples/weblate), as SQL: [source.sql](source.sql). `prisma db pull` writes them up as [schema.prisma](schema.prisma) (with 9 changes so that Prisma accepts it, listed in its header), and from that write-up Prisma and every ORM hekireki generates create tables of their own; their SQL is in [sql/](sql), dumped the way source.sql is, and held to it here.

`=` identical · `≈` the same but for constraint and index names, and the order of columns and statements · `≠` tables written differently, or statements one side has and the other does not. The last column holds each ORM's SQL to what Prisma itself creates from the same write-up: a difference there is the ORM's or hekireki's, one only against source.sql is something the write-up does not say.
